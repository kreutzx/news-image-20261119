Entry for the make.fun bounty [news-image-20261119](https://make.fun/bounty/news-image-20261119): one image that sums up the world news of **Thursday, 19 November 2026**. It is a newspaper front page — masthead, the day's lead story, a dozen further stories from every region, a UTC timeline of the day and an in-brief column — composed programmatically with Python and PIL, with every word set as real type.

## Run

```
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This copies `entry.png` to `out/entry.png`. Python 3 standard library only; no network needed.
